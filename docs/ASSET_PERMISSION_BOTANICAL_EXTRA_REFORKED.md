# Botanical Machinery Extra Reforked asset permission

Permission was granted by **BOLT_M4G1C**, maintainer/developer of Botanical Machinery Extra Reforked, for Divine Machinery Legacy to use the original GUI textures and other visual assets while backporting the mod to Minecraft 1.7.10.

Date recorded: **2026-08-15**

The permission request explicitly described:
- a Minecraft 1.7.10 backport named **Divine Machinery Legacy**;
- use of Botanical Machinery Extra Reforked as the main reference for machine tiers, upgrades, sparks, catalysts and related systems;
- temporary use of the original GUI textures and other visual assets during development;
- a plan to replace/redraw those textures later;
- public development in `NOSFERATU-ll/Divine-Machinery-Legacy`;
- credit to the original project.

Developer response:

> Yeah, you can. I'm not actively working on the mod anymore, glad that someone is porting it to 1.7.10

The original permission screenshot was supplied by the project owner in the development conversation. Keep this transcript with the source so the allowed scope remains explicit even after the temporary upstream artwork is replaced.
